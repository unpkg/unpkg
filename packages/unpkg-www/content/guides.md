# Guides

UNPKG guides. Start with loading files; the rest build on the same URL pattern.

Source page: https://unpkg.com/guides

- [Loading files](https://unpkg.com/guides/loading-files.md): the URL pattern, versions and tags, entry points and exports, directory listings
- [Nobuild apps](https://unpkg.com/guides/nobuild-apps.md): import maps and native ES modules with no build step
- [Inline scripts](https://unpkg.com/guides/inline-scripts.md): run TypeScript/JSX inline with the `/run` helper
- [Browser modules](https://unpkg.com/guides/browser-modules.md): esm.unpkg.com: every parameter, stylesheet handling, errors
- [Metadata API](https://unpkg.com/guides/metadata-api.md): `?meta` JSON: paths, sizes, types, integrity hashes
- [Cache performance](https://unpkg.com/guides/cache-performance.md): permanent URLs, redirects, and the pinning trade-off
- [Supply chain security](https://unpkg.com/guides/supply-chain-security.md): UNPKG Shield, and how it differs from SRI
